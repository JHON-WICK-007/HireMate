Q1 · Technical
Welcome! Let's start with a warm-up. Can you explain the difference between REST and GraphQL APIs? When would you choose one over the other?
YS
REST uses fixed endpoints where each URL returns a specific resource, while GraphQL uses a single endpoint and lets the client specify exactly what data it needs. I'd choose REST for simple CRUD services and GraphQL when the client needs flexible data fetching — like a mobile app that needs different fields than a web app.

Q2 · Technical
Good answer! You mentioned flexible data fetching — let's build on that. How does GraphQL handle the N+1 query problem, and what's the common solution?
YS
The N+1 problem happens when resolving a list triggers individual DB queries for each item. GraphQL doesn't solve this automatically — it's handled using the DataLoader pattern, which batches and caches requests within a single tick of the event loop.
